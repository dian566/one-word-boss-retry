One word for the boss: **Micromanager**.

## Entry

Run `python3 main.py` — it writes the single-word entry to `/output/entry.txt`.
The file holds exactly one word (13 characters, within the 30-character limit),
with no trailing newline and no extra whitespace.

## Why this word

A micromanager is the boss everyone recognises instantly: the one who hovers
over every detail, double-checks every message before it goes out, and turns
a five-minute task into a day of status updates. One word, zero ambiguity.
